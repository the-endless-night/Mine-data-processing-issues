# 基于FTTransformer的数据变换与误差分析项目

## 项目概述
本项目使用FTTransformer深度学习网络对A.xlsx(10000*99)数据集进行变换，使变换后的结果与B.xlsx(10000*1)数据集尽可能接近，并分析误差来源。项目主要包括数据清洗、预处理、模型训练与评估等步骤。

## 数据说明
- **A.xlsx**: 包含10000行*99列的输入数据，每一行是一个样本，99列是特征
- **B.xlsx**: 包含10000行*1列的目标数据，每行对应A文件中相同行的目标值
- 两个文件的第0行起就是数据，没有表头

## 技术方案
项目采用FTTransformer（Feature Tokenizer Transformer）模型，这是一种专为表格数据设计的深度学习架构。相比传统的神经网络，FTTransformer能更好地捕捉特征间的关系，对表格数据进行更有效的建模。

### 模型选择与理论依据
本研究采用FTTransformer模型对A.xlsx中的高维特征数据进行建模和变换，目标是逼近B.xlsx中的目标值。FTTransformer是一种基于Transformer结构的表格数据建模方法，相较于传统全连接网络，其优势在于：
- **能有效捕捉不同维度之间的交互信息**：通过自注意力机制，FTTransformer能够动态建模特征间的复杂关系。
- **支持特征选择与注意力机制，自适应特征加权**：模型能够根据特征的重要性分配不同的权重，从而提升建模效果。
- **在处理高维数据时表现出更优的泛化能力和鲁棒性**：特别适用于矿山监测数据这种具有高维属性和噪声的复杂数据。

技术方案主要包括：
1. **数据清洗**：处理缺失值、异常值检测与处理、数据对齐等
2. **数据预处理**：标准化、数据分割、特征工程等
3. **模型训练**：使用FTTransformer进行特征转换
4. **误差分析**：评估预测结果、分析误差来源

## 文件结构
- `main.py` - 主程序入口
- `data_preprocessing.py` - 数据加载、清洗和预处理
- `model.py` - FTTransformer模型定义
- `train.py` - 模型训练逻辑
- `evaluate.py` - 模型评估和误差分析
- `README.md` - 项目说明文档

## 运行方法
1. 确保A.xlsx和B.xlsx文件放在正确位置（与main.py同目录）
2. 安装所需依赖：
   ```
   pip install pandas numpy torch matplotlib scikit-learn scipy tqdm
   ```
3. 运行主程序：
   ```
   python main.py
   ```

## 误差分析
模型通过以下方面分析预测误差的来源：
1. **系统性偏差**：检查预测值与实际值之间是否存在系统性差异
2. **异常值影响**：评估数据中异常值对模型性能的影响
3. **数据噪声**：分析误差变异的大小，判断数据噪声水平
4. **模型欠拟合/过拟合**：通过误差与预测值的相关性等分析模型拟合情况
